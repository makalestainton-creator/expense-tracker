### Expense Tracker
This is a simple yet comprehensive multi-page program where a user can: 
- add an expense
- delete an expense
- edit an expense

It catches errors such as empty input fields and negative or zero amount inputs.
Adding an expense at 12 midnight? then the intuitive dark mode is your closest ally. The Interactivity of the page is at its best and will keep improving in later versions and updates. Be sure to be a happy user!!
